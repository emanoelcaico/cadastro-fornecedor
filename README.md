FACULDADE GRAN (https://faculdade.grancursosonline.com.br/)



Projeto Disciplina Projeto Integrador



\## Descrição

Sistema full stack de cadastro de fornecedores e produtos, com associação N:N entre eles.



\## Estrutura

\- backend/    -> API Node.js + Express + Sequelize (porta 3001)

\- frontend/   -> Interface React + Vite (porta 5173)

\- disciplina/ -> Exercício do Passo 2 (servidor HTTP puro, porta 3000)



\## Como rodar



\### Backend

cd backend

npm install

npm run dev



\### Frontend

cd frontend

npm install

npm run dev



\### Exercício da disciplina (Passo 2)

cd disciplina

node app.js
