# FACULDADE GRAN
Projeto Disciplina Projeto Integrador
Aluno: Emanoel do Nascimento Alves

## Funcionalidades Implementadas
- [x] Cadastro de Produtos (Create, Read, Delete)
- [x] Cadastro de Fornecedores (Create, Read, Delete)
- [x] Associação N:N entre Produtos e Fornecedores
- [x] Validação de dados (CNPJ único, Código de Barras único)
- [x] Mensagens de sucesso e erro exatamente como no roteiro
- [x] Backend Node.js (Express + Sequelize + MySQL)
- [x] Frontend React.js (Vite)
- [x] Integração Full Stack (Frontend consumindo API na porta 3000)

## Como rodar
### Backend
cd backend
npm install
npm run dev

### Frontend
cd frontend
npm install
npm run dev

### Disciplina (Passo 2)
cd disciplina
node app.js
